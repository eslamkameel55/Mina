# مطعم مينا – فندق تلال الرياض | MeNa Restaurant – Tilal Riyadh Hotel

موقع إلكتروني احترافي متكامل وفاخر لمطعم **MeNa Restaurant (مطعم مينا)** الكائن داخل **فندق تلال الرياض (Tilal Riyadh Hotel)** في مدينة الرياض، المملكة العربية السعودية.

---

## 🌟 نظرة عامة ومميزات المشروع

1. **هوية بصرية فاخرة مستوحاة من الضيافة الأندلسية والمعاصرة:**
   - لوحة ألوان دافئة وراقية: عاجي دافئ (`#F7F3EC`)، أخضر زيتوني عميق (`#344438`)، ذهبي هادئ (`#B69A65`)، وبني دافئ (`#604B3C`).
   - خلو كامل من التصاميم المكررة والقوالب التجارية السريعة، واعتماد معايير تصميم الفنادق العالمية (Luxury Hospitality Architecture).

2. **دعم ثنائي اللغة أصيل (العربية أولاً):**
   - واجهة عربية أصيلة بنظام RTL مع خط عربي فاخر (Cairo).
   - واجهة إنجليزية كاملة بنظام LTR مع خطوط متناسقة (Playfair Display & Plus Jakarta Sans).
   - زر تبديل اللغة الفوري مع حفظ الخيار في التخزين المحلي للمتصفح.
   - دعم التسميات والأوصاف ثنائية اللغة لجميع الأطباق والتصنيفات والمحتوى.

3. **قاعدة بيانات ونظام إدارة محتوى متكامل (Admin Dashboard):**
   - وصول محمي ومصرح به عبر المسار الإداري `/admin`.
   - مصادقة آمنة باستخدام JWT وتشفير كلمات المرور عبر `bcryptjs`.
   - إدارة كاملة (CRUD) للأطباق (الاسم، الوصف، السعر، العملة، مسببات الحساسية، المكونات، حالة التوفر، حالة النشر، والأطباق المميزة).
   - إدارة التصنيفات وتحديد ترتيب العرض وحمايتها من الحذف العرضي عند ارتباطها بأطباق.
   - مكتبة صور ومعرض تفاعلي (Gallery) مع دعم رفع الصور الفعلي إلى الخادم عبر Multer وفحص الامتدادات المسموحة (JPEG, PNG, WebP) وحجم الملف.
   - سجل تدقيق إداري (Audit Logs) لتوثيق جميع العمليات والتغييرات الإدارية مع التاريخ والمنفذ.
   - تنزيل نسخة احتياطية فورية من قاعدة البيانات بصيغة JSON.

4. **نظام الحجوزات والتواصل المباشر:**
   - نموذج حجز طاولة مسبق (يمكن تفعيله أو تعطيله من لوحة التحكم بضغطة زر).
   - إدارة وتحديث حالات الحجوزات (جديد، قيد التأكيد، مؤكد، ملغى) مع إمكانية تدوين ملاحظات الطاقم.
   - روابط اتصال مباشر عبر الهاتف والبريد الإلكتروني المعتمد لمطعم مينا وفندق تلال الرياض.
   - خريطة تفاعلية مدعومة بإحداثيات حقيقية للمطعم (`24.6760592, 46.7798192`) وزر نسخ العنوان والحصول على الاتجاهات.

5. **تحسين محركات البحث والأمان (SEO & Security):**
   - تضمين Schema.org `Restaurant` المنظمة لمحركات البحث.
   - دعم OpenGraph و Twitter Cards و Sitemap و Robots.txt.
   - سياسة خصوصية واضحة تمنع تخزين أي بيانات بنكية وتضمن حماية خصوصية الضيوف.

## 🛠️ البنية التقنية (Tech Stack)

- **الواجهة الأمامية (Frontend):** React 19 + TypeScript + Vite.
- **التنسيق والأنماط (Styling):** Tailwind CSS v4 + خطوط Google Fonts (Cairo & Playfair Display).
- **الواجهة الخلفية (Backend):** Node.js + Express (مسارات `/api/*`).
- **التخزين وقاعدة البيانات:**
  - محرك تخزين محلي دائم `data/mena_db.json` مع كتابة ذرية آمنة (Atomic Writes).
  - ملف المخطط الكامل `schema.sql` المخصص لقواعد بيانات PostgreSQL أو Supabase مع سياسات الأمان على مستوى الصفوف (Row Level Security - RLS).
- **رفع الملفات:** Multer لمعالجة وحفظ الصور في مجلد `/uploads`.
- **الأمان والمصادقة:** JSON Web Tokens (JWT) + Hashing عبر bcryptjs.

## 🚀 التشغيل والتثبيت المحلي

### المتطلبات الأساسية
- Node.js (الإصدار 18 أو أحدث).
- npm أو pnpm أو yarn.

### خطوات التشغيل
1. استنساخ المشروع وتثبيت الحزم:
   ```bash
   npm install
   ```

2. إعداد ملف البيئة `.env`:
   انسخ ملف `.env.example` إلى `.env`:
   ```bash
   cp .env.example .env
   ```

3. تشغيل خادم التطوير (Full-Stack Dev Server):
   ```bash
   npm run dev
   ```
   سيعمل الخادم على المنفذ `http://localhost:3000`.

4. بناء النسخة الإنتاجية (Production Build):
   ```bash
   npm run build
   npm run start
   ```

## 🗄️ إعداد قاعدة البيانات الإنتاجية (PostgreSQL / Supabase)

يحتوي المشروع على ملف `schema.sql` جاهز للتنفيذ الفوري. لنقل قاعدة البيانات إلى PostgreSQL أو Supabase:

1. أنشئ مشروعاً جديداً في [Supabase](https://supabase.com) أو أي مزود PostgreSQL.
2. افتح **SQL Editor** في لوحة تحكم Supabase.
3. انسخ محتوى الملف `schema.sql` وشغّله.
4. سيتم إنشاء الجداول التالية مع مفاتيحها وفهارسها وسياسات الـ RLS:
   - `site_settings`
   - `categories`
   - `dishes`
   - `gallery_images`
   - `reservations`
   - `admin_profiles`
   - `admin_audit_logs`

## 🌐 تعليمات ربط النطاق المخصص والنشر (Deployment & Domain Binding)

### 1. النشر على Google Cloud Run / VPS
- التطبيق يدعم تشغيل خادم Express مع ملفات dist المبنية عبر الأمر `npm run start`.
- المنفذ التلقائي هو `3000` أو المعرف في متغير البيئة `PORT`.

### 2. ربط النطاق (Domain Binding)
- توجه إلى لوحة مزود النطاق الخاص بك (مثل Cloudflare أو GoDaddy أو استضافة الفندق).
- أضف سجل `A Record` يوجه إلى عنوان IP الخاص بالخادم.
- أو أضف سجل `CNAME` يوجه النطاق الفرعي (مثل `mena.tilalhotels.com`) إلى رابط الاستضافة.
- فعّل شهادة SSL المجانية عبر Let's Encrypt أو Cloudflare SSL لضمان التشفير ببروتوكول HTTPS.
